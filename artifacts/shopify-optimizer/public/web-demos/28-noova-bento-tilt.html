Animation System

GSAP ScrollTrigger

AnimatedTitle Component

Cada palabra es un span con CSS inicial 3D extremo. GSAP anima a posición neutral con stagger 0.02s. El efecto es de "palabras cayendo desde el espacio".

.animated-word { transform: translate3d(0,-100px,-500px) rotateX(90deg); opacity: 0; } // GSAP ScrollTrigger: gsap.to('.animated-word', { transform: 'translate3d(0,0,0) rotateX(0)', opacity: 1, stagger: 0.02, duration: 0.6, ease: 'power2.out', scrollTrigger: { trigger: el } })
