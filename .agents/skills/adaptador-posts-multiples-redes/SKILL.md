# Adaptador de Posts para Múltiples Redes Sociales

Cuando el usuario proporcione contenido, una idea, un post base o un briefing, genera versiones optimizadas para cada red social solicitada.

## Redes Soportadas y Sus Particularidades

| Red | Límite | Tono | Hashtags | Emojis |
|-----|--------|------|----------|--------|
| **Instagram** | 2.200 chars (feed) / 150 (stories texto) | Visual, aspiracional, cercano | 5-15 relevantes al final | Sí, con moderación |
| **Facebook** | 63.206 chars (óptimo <80) | Conversacional, comunidad | 2-5 o ninguno | Sí |
| **X / Twitter** | 280 chars | Directo, opinión, wit | 1-2 máx | Opcional |
| **LinkedIn** | 3.000 chars | Profesional, valor, insight | 3-5 al final | Escasos |
| **TikTok** | 2.200 chars (caption) | Fresco, trending, casual | 5-10 trending | Sí |
| **Pinterest** | 500 chars (pin) | Descriptivo, inspiracional | 5-10 en descripción | Escasos |
| **YouTube** | 5.000 chars (descripción) | Informativo, SEO-friendly | 3-5 (shorts) | Sí |
| **Threads** | 500 chars | Casual, conversación | Pocos o ninguno | Sí |

## Flujo de Trabajo

1. **Analiza** el contenido fuente: tema, objetivo (awareness, conversión, comunidad, educación), tono de marca.
2. **Adapta** para cada red solicitada:
   - Reformatea según la estructura nativa de cada plataforma.
   - Ajusta la longitud, el hook de apertura y el CTA.
   - Selecciona hashtags relevantes (no copiar el mismo set en todas).
   - Adapta el tono: lo que funciona en LinkedIn es rígido en TikTok.
3. **Genera** versiones completas listas para publicar.
4. **Sugiere** el mejor horario de publicación para cada red si el usuario lo solicita.

## Formato de Salida

Para cada red social:
```
### [RED SOCIAL] — [Tipo de formato: Feed / Story / Reel / etc.]

[Contenido adaptado completo]

Hashtags: #ejemplo #hashtag
```

## Instrucciones Clave

- Nunca uses los mismos hashtags en todas las redes.
- El hook de los primeros 3 segundos es crítico en TikTok/Reels; el de las primeras líneas en LinkedIn/Facebook.
- En Instagram, el copy va primero y los hashtags al final o en el primer comentario.
- En LinkedIn, añade un insight de valor o una pregunta al final para generar comentarios.
- Si el usuario no especifica redes, genera para Instagram, X, LinkedIn y Facebook por defecto.
- Indica si se necesita imagen/video/carrusel específico para cada formato.
- Si el contenido original es en español, mantén español a menos que se indique lo contrario.
