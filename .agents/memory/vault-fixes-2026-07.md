## Rule
ProjectVault FOLDER_CONFIG **must** include all file types generated by every tool:
- `fs-pro-video`, `fs-pro-video-upscaled` → "videos" folder
- `fs-pro-image`, `fs_pro_image`, `fs-pro-image-edit`, `fs-pro-bg-removed`, `fs-pro-bg-replaced`, `fs-pro-upscaled` → "images" folder
- `fs-pro-tts`, `fs-pro-sfx`, `fs-pro-music` → "audio" folder
- `3d_model` → "3d" folder
- `ad-studio-video`, `ad-final`, `ad-image` → included in videos + publicidad

## Why
Files generated by Fusion Studio Pro and Ad Studio saved with these specific fileTypes were falling into "Otros" because ProjectVault only had 12 generic types. Users couldn't find generated videos/audio/3D files.

## Video Audit Backend
- POST `/api/projects/:projectId/vault/:fileId/audit-video`
- POST `/api/vault/global/:fileId/audit-video`
- Uses `askGeminiWithUrls()` with originalUrl; fallback to `askClaude()` on error or if no public URL
- Returns `{ analysis, fileId, title }`

## Entity Sorting
- vault.ts `/vault/global/entities`: project entities now include `latestDate: max(createdAt)` field
- Sort is by `latestDate desc` then `fileCount desc` (most recently active entity first)

## Date Display
- GlobalVault file rows: `toLocaleString("es-ES", { day:"2-digit", month:"short", hour:"2-digit", minute:"2-digit" })`
- ProjectVault folder cards: same format with time
- `formatDate()` in ProjectVault already included time; folder card "Último:" was missing it → fixed
