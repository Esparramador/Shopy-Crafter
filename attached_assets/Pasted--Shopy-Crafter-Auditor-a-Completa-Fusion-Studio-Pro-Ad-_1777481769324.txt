## Aplicación rápida

```bash
# 1. Descargar y extraer
cd ~/Downloads && tar -xzf shopycrafter-audit.tar.gz

# 2. Variables de entorno (en Replit Secrets):
ENCRYPTION_KEY=<64 chars hex>      # MANDATORY
ELEVENLABS_API_KEY=<nueva, revocada antigua>
RUNWAY_API_KEY=<nueva, revocada antigua>
GEMINI_API_KEY=<existente>
REPLICATE_API_TOKEN=<existente o per-project>
VAPID_SUBJECT=mailto:tu-email      # para push

# 3. Instalar dependencias
cd artifacts/api-server
pnpm add web-push @types/web-push fluent-ffmpeg ffmpeg-static archiver
pnpm add -D @types/fluent-ffmpeg @types/archiver

# 4. Copiar archivos según 09-APPLY-GUIDE.md
# 5. Verificar typecheck
pnpm -F @workspace/api-server build
pnpm -F @workspace/shopify-optimizer typecheck

# 6. Si OK, arrancar dev y probar 1-2 endpoints
pnpm -F @workspace/api-server dev
```
