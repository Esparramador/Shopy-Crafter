PASO 3: BOTÓN "AUTO-ESTIMAR CON IA" (modal individual)
═══════════════════════════════════════════════════════════════════

Cuando se clickea EN EL MODAL "Estructura de Costes Real":

1. Mostrar loading state ("Analizando producto con IA…" 
   con spinner teal sobre el botón)
2. POST /api/pricing/estimate-cogs con productId
3. Backend:
   a. Detecta categoría (clasifyProductType)
   b. Llama estimador (cogsEstimator)
   c. Guarda en cogs_calculations
   d. Retorna JSON
4. Frontend: rellena CADA input del modal con valores reales
   - Animación: cada campo aparece con stagger (50ms entre cada uno)
5. Mostrar al final un toast: "COGS estimado · Margen: X% · 
   Confianza: Y%"
6. Si confidence < 0.6 → toast warning amarillo:
   "Estimación tentativa, revisa los assumptions"

PASO 4: BOTÓN "AUTO-ESTIMAR TODOS" (header)
═══════════════════════════════════════════════════════════════════

1. Confirmación modal: "Vas a estimar COGS para N productos. 
   Coste IA estimado: ~€X. ¿Continuar?"
2. POST /api/pricing/estimate-cogs/batch

   "Procesando: 23/87 productos · 3 errores"

   - Margen bruto promedio: X%
   - Productos con margen <20%: N (link "ver detalles")
