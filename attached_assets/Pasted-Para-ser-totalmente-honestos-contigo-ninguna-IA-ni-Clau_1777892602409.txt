La Arquitectura del "Web Lab" (Cómo debe procesarlo tu sistema)
Fase de Extracción (El ADN en JSON):
Cuando el usuario pone la URL de Instagram, la IA no debe generar la web todavía. Primero, debe devolver un JSON con el "Sistema de Diseño".
(Ejemplo: { "primary_color": "#FF5733", "font_heading": "Montserrat", "style": "minimalista y agresivo" }).

Uso de Variables CSS (El secreto de la edición):
Claude DEBE generar el CSS usando variables (:root { --primary: #FF5733; }). Esto es lo que permitirá que tu plataforma Shopy Crafter cambie los colores en tiempo real si el usuario mueve un deslizador, sin tener que regenerar todo el código.

El Entorno de Renderizado (Iframe o Shadow DOM):
Para que las dos cosas (HTML y CSS) se "mezclen visualmente" de forma segura en tu plataforma sin romper el diseño de tu propio SaaS, debes inyectar el código generado por Claude dentro de una etiqueta <iframe> o usar un Shadow DOM en tu frontend.

CERO CHARLA: No incluyas saludos, explicaciones, ni texto introductorio. Devuelve ÚNICAMENTE el código solicitado.

SEPARACIÓN DE ARCHIVOS: Si se te pide HTML y CSS, devuélvelos separados claramente por delimitadores personalizados, por ejemplo: ===HTML_START=== [código] ===HTML_END=== y ===CSS_START=== [código] ===CSS_END===.
