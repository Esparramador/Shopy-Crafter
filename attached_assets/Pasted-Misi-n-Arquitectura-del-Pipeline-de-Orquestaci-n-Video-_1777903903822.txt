Misión: Arquitectura del Pipeline de Orquestación "Video-to-Audio" (Delegación Estricta de APIs)
Actúa como Lead Backend Engineer. Vamos a crear el flujo de trabajo en /services/marketingPipeline.js que toma un vídeo mudo, URLs de contexto y un prompt del usuario, y devuelve un vídeo final con voz en off.

REGLA DE ORO DE LA ARQUITECTURA: Tenemos APIs dedicadas para cada tarea. Debes estructurar el código para que pase la información en cadena de una API a otra de manera secuencial.

Paso 1: El Cerebro Analítico (Gemini / Claude)

Acción A (Visión): Envía el vídeo a la API de Gemini (o Claude si soporta el formato) para extraer un timeline en formato JSON de los eventos visuales.

Acción B (Scraping): Nuestro backend extrae el texto de la web/Instagram del cliente y se lo pasa a Claude/Gemini.

Acción C (Guionización): Claude/Gemini cruza el timeline, la información extraída y la idea del usuario. Genera un guion milimétrico utilizando etiquetas <break time="X"/> (SSML) para sincronizar las pausas de la voz con los cambios de plano del vídeo.

Paso 2: El Motor de Voz (ElevenLabs)

Toma EXCLUSIVAMENTE el guion de texto (con las etiquetas SSML) devuelto por Claude/Gemini en el Paso 1.

Envía este texto a la API de ElevenLabs (endpoint /text-to-speech).

Recibe y guarda temporalmente el archivo de audio .mp3 generado.

Paso 3: El Ensamblador Final (FFmpeg en Replit)

Utiliza la librería de FFmpeg de nuestro entorno.

Toma el .mp4 original y el .mp3 generado por ElevenLabs.

Fusiona ambos sin re-renderizar el vídeo (usando codec: copy para el vídeo) y genera el final_output.mp4.

Tu tarea: Escribe la estructura de la clase o función principal que encadena estas promesas (await step1, await step2, await step3). Asegúrate de inyectar logs de consola entre cada paso para que podamos medir en milisegundos cuánto tarda cada API en responder.

El toque maestro para la Experiencia de Usuario (UI/UX)
Dado que este proceso es hiperprofesional, requiere tiempo. Entre que Gemini analiza el vídeo, Claude escribe el guion, ElevenLabs genera el audio y FFmpeg lo junta, podrían pasar de 15 a 45 segundos de procesamiento real en tu servidor.
