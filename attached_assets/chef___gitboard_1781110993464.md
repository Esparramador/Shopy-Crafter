# GitBoard Design System

## Overview

GitBoard is a repository-structured, diff-inspired design system for Git workflow tools and code review platforms. It centers around the familiar addition/deletion color coding of diffs, with green and red serving as functional primaries rather than decorative choices. The compact layout is optimized for scanning code changes, reviewing pull requests, and navigating repository structures. Every component draws from the mental model of version control, making the interface instantly recognizable to developers.

---

## Colors

- **Primary** (#22C55E): Green — additions, approvals, merged PRs
- **Secondary** (#EF4444): Red — deletions, rejections, conflicts
- **Tertiary** (#3B82F6): Blue — links, info, branch references
- **Background** (#FAFAFA): Page background
- **Surface** (#FFFFFF): Cards, panels, file viewers
- **Success** (#22C55E): Merged, checks passed, additions
- **Warning** (#D97706): Pending review, draft PR
- **Error** (#EF4444): Checks failed, conflicts, deletions
- **Info** (#3B82F6): Open PRs, comments, info notes

## Spacing

- **Base unit:** 4px (compact)
- **Scale:** `4px / 8px / 12px / 16px / 24px / 32px / 48px / 64px`
- **Component padding:** Buttons `8px 14px`, Cards 16px, Inputs `8px 12px`
- **Section spacing:** 32px between sections, 48px for page headers
- **Diff line height:** 20px fixed for consistent diff viewing
- **File tree indent:** 16px per depth level

## Border Radius

- **None** (0px): Diff lines, code blocks (inner)
- **Small** (3px): Inline code, tiny badges
- **Medium** (6px): Cards, buttons, inputs, panels
- **Large** (8px): Modal containers, dropdown menus
- **XL** (12px): Feature cards, onboarding
- **Full** (9999px): Avatars, status indicators, pill labels

## Elevation

GitBoard uses a flat aesthetic with borders. Shadows are reserved for floating elements.
- **Subtle**: None (use 1px #E4E4E7). Cards, file viewers, tables.
- **Medium**: 2px offset, 6px blur, #000000 at 6%. Dropdown menus, popovers.
- **Large**: 8px offset, 24px blur, #000000 at 10%. Modals, command palette.
- **Overlay**: 9999px ring #000000 at 35%. Backdrop behind modals.
- **Diff**: inset 3px 0 0` (color varies). Diff line change indicator bar.
Diff shadow colors: additions `inset 3px 0 0 #22C55E`, deletions `inset 3px 0 0 #EF4444`, unchanged None.

## Do's and Don'ts

1. **Do** use green exclusively for additions, approvals, and merged states; red for deletions, failures, and rejections.
2. **Do** render all code content in JetBrains Mono at 13px with `1.6` line height for diff readability.
3. **Do** use the `inset 3px 0 0` left-border pattern for diff line change indicators.
4. **Don't** swap green and red semantics; developers have strong expectations for these colors in git contexts.
5. **Don't** use shadows on file viewers or diff panels; flat borders keep the interface clean and scannable.
6. **Don't** exceed 14px for body text in compact views; the 4px-base system demands restraint.
7. **Do** provide clear PR status badges using the defined pill-shaped status chip system.
8. **Don't** use display-size typography for repository names; subhead is the maximum size in list contexts.
9. **Do** maintain the 20px fixed line height for all diff view lines to ensure alignment.
10. **Don't** apply colored backgrounds to more than the changed lines in a diff; context lines stay white.
