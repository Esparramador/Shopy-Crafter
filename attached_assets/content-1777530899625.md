# API Pricing & Costs

Each generation you run in the Ruway API costs credits. Credits can be purchased
for $0.01 per credit in the developer portal for an organization. Sales tax may
apply depending on your location. [Create an account](https://dev.runwayml.com/) to use the Runway API.
