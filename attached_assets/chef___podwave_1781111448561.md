# PodWave Design System

## Overview

PodWave is an audio-centric design system crafted for podcast platforms and audio content apps. Built on a dark background, it draws visual inspiration from waveforms and audio visualizers with glowing purples and teals. The system uses rounded, pill-shaped playback controls and generous spacing to create an immersive listening experience.

---

## Colors

- **Color Primary** (#7C3AED): Primary actions, now-playing glow
- **Color Secondary** (#14B8A6): Secondary accents, categories
- **Color Tertiary** (#F97316): Highlights, live indicators
- **Surface Base** (#111111): Page background
- **Color Success** (#22C55E): Downloaded, saved
- **Color Warning** (#F97316): Live, recording
- **Color Error** (#EF4444): Error states
- **Color Info** (#14B8A6): New episode, updates

## Spacing

Base unit: **8px**.
- **xs**: 4px — Inline icon gaps
- **sm**: 8px — Tight padding, chip gaps
- **md**: 16px — Card padding
- **lg**: 24px — Section gaps
- **xl**: 32px — Layout margins
- **2xl**: 48px — Hero section spacing
- **3xl**: 64px — Major layout breaks

## Border Radius

- **radius-sm** (6px): Chips, small tags
- **radius-md** (12px): Cards, inputs, panels
- **radius-lg** (16px): Modals, large containers
- **radius-pill** (9999px): Playback controls, play button

## Elevation

Dark-mode glow system with colored ambient light.
- **shadow-sm**: 1px offset, 3px blur, #000000 at 40%. Resting cards.
- **shadow-md**: 4px offset, 12px blur, #000000 at 50%. Hovered elements.
- **shadow-lg**: 8px offset, 24px blur, #000000 at 60%. Modals, overlays.
- **shadow-playing**: 20px glow #7C3AED at 50%. Now-playing glow.
- **shadow-teal**: 14px glow #14B8A6 at 35%. Secondary highlights.

## Do's and Don'ts

1. **Do** use the purple glow (shadow-playing) exclusively for active/now-playing states.
2. **Do** use pill-shaped controls for all playback-related UI (play, pause, skip, scrub).
3. **Do** maintain dark surfaces throughout; avoid introducing light panels that break immersion.
4. **Don't** overuse the tertiary orange; reserve it for live indicators and urgent highlights only.
5. **Don't** mix rounded and sharp corners; all elements must use the rounded radius system.
6. **Do** use the teal secondary for category labels, tags, and supplementary navigation.
7. **Don't** place light text below #A3A3A3 on dark backgrounds; maintain WCAG AA contrast minimums.
8. **Do** ensure waveform-style visualizers use the primary purple gradient when actively playing.
9. **Don't** use flat black (#000000) as a surface; always use the defined surface tokens for depth.
10. **Do** keep the mini-player bar fixed at the bottom with surface-sunken background.
