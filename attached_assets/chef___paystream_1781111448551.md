# PayStream
Fast, modern, friction-free -- payments at the speed of thought.

## Overview

PayStream is a sleek, conversion-optimized design system for payment processing and checkout flows. It pairs a confident purple with complementary teal and coral to guide users through transactions with clarity and trust. Every component minimizes cognitive load and maximizes completion rates. The system prioritizes speed, security signals, and a single clear path to payment.

## Colors

- **Primary** (#7C3AED): Purple -- CTAs, payment buttons, branding
- **Secondary** (#14B8A6): Teal -- success states, confirmations
- **Tertiary** (#F43F5E): Coral -- urgency, error states, alerts
- **Neutral** (#6B7280): Gray -- secondary text, borders, placeholders
- **Background** (#FFFFFF): App background, checkout canvas
- **Surface** (#F9FAFB): Cards, form sections
- **Success** (#14B8A6): Payment complete, verified
- **Warning** (#F59E0B): Review needed, card expiring
- **Error** (#F43F5E): Payment failed, validation errors
- **Info** (#7C3AED): Informational notes, processing

## Do's and Don'ts

1. **Do** limit each screen to one primary CTA -- in checkout, "Pay Now" must be the only dominant button.
2. **Do** display trust badges (SSL lock, card brand logos, security seals) near payment inputs.
3. **Do** use the lock icon beside sensitive fields (card number, CVV) to reinforce security.
4. **Don't** ask for information you can auto-detect (country from card BIN, card type from number).
5. **Do** keep form fields to an absolute minimum; every extra field reduces conversion.
6. **Don't** redirect users away from the checkout page unexpectedly; keep flows linear.
7. **Do** show a clear order summary with itemized totals visible at all times during checkout.
8. **Don't** use the Coral/Destructive color for anything other than errors and critical warnings.
9. **Do** provide instant inline validation on card number, expiry, and CVV fields.
10. **Don't** auto-advance focus between fields without clear user expectation; let tab order flow naturally.
