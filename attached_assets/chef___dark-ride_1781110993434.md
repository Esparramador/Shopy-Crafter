# Dark Ride

## Overview
Dark Ride is a bold, black-dominant design system built for utility and motion. Rooted in the experience of urban transportation, it pairs unapologetic black canvases with crisp white text and strategic blue accents to create interfaces that are fast to scan and decisive to use. The aesthetic is premium yet functional — every element serves the journey from point A to point B with zero unnecessary decoration.

## Colors
- **Primary** (#276EF1): Primary action buttons, selected states, map route lines, and interactive highlights — Uber Blue
- **Primary Hover** (#1E54B7): Hover and pressed state for primary interactive elements — Deep Blue
- **Secondary** (#000000): Hero backgrounds, premium surfaces, and brand-forward sections — Uber Black
- **Neutral** (#6B6B6B): Secondary text, inactive icons, supporting metadata — Mid Gray
- **Background** (#FFFFFF): Main app background for ride-booking flow, map canvas tint — White
- **Surface** (#F6F6F6): Card backgrounds, bottom sheet surfaces, input fields — Light Gray
- **Surface Dark** (#000000): Dark-mode surfaces, ride-in-progress screen, driver view — Black
- **Text Primary** (#000000): Primary text on light backgrounds — Black
- **Text Secondary** (#6B6B6B): Timestamps, ETAs, secondary labels — Mid Gray
- **Text Inverse** (#FFFFFF): Text on dark/black backgrounds — White
- **Border** (#E2E2E2): Input borders, card dividers, section separators — Pale Gray
- **Success** (#05A357): Ride confirmed, trip complete, available driver — Road Green
- **Warning** (#FFC043): Surge pricing, high demand, dynamic pricing alerts — Caution Yellow
- **Error** (#E54937): Ride cancelled, payment failed, error states — Alert Red

## Typography
- **Display Font**: DM Sans — loaded from Google Fonts
- **Body Font**: DM Sans — loaded from Google Fonts
- **Code Font**: JetBrains Mono — loaded from Google Fonts

DM Sans provides the geometric precision and modern weight range needed for a transportation interface where type must be instantly legible at any size. Display headings use weight 700 at -0.02em letter-spacing for bold, confident headlines ("Where to?"). Body text uses 14px weight 400 for addresses and details. Price displays use weight 700 at 20px+. ETA and timing displays use weight 500 in a slightly larger size for at-a-glance scanning. The font works equally well in light and dark modes.

Type scale: 12px (micro/label) / 14px (body) / 16px (subtitle) / 20px (price/ETA) / 24px (section title) / 36px (hero prompt) / 52px (splash/price)

## Elevation
Elevation plays a critical role in separating map content from UI panels. Bottom sheets use `box-shadow: 0 -4px 16px rgba(0, 0, 0, 0.08)` rising from the bottom over the map. Ride option cards use `box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08)`. The "Where to?" search bar floats over the map with `box-shadow: 0 2px 8px rgba(0, 0, 0, 0.12)`. Modals use `box-shadow: 0 8px 24px rgba(0, 0, 0, 0.16)`. In dark mode, elevation shifts to surface brightness (#111111, #1A1A1A, #222222) rather than shadows.

## Components
- **Buttons**: Primary buttons have #000000 background, white text, 8px border-radius, height 52px (large and thumb-friendly), full-width, font-weight 700, font-size 18px. This is the signature "Confirm" button. Secondary variant uses #F6F6F6 background with #000000 text. Outline variant has 2px solid #000000 border. Small buttons are 40px height. Blue (#276EF1) is used for selected states and links, not for primary CTAs.
- **Cards**: Ride option cards are white, 8px border-radius, 16px padding, showing vehicle illustration (48px), ride type name at weight 700, ETA at 14px, and price right-aligned at weight 700. Selected card has 2px solid #000000 border. Stacked vertically with 8px gap. Trip receipt cards use a clean list layout with line items and a bold total.
- **Inputs**: "Where to?" input has #F6F6F6 background, 8px border-radius, height 52px, padding 0 16px, font-size 16px, with a magnifying glass or green/red dot icon for pickup/dropoff. Focus state adds 2px solid #000000 border. Address autocomplete shows in a bottom sheet list with location pin icons.
- **Chips**: Filter chips (ride types) are pill-shaped, #F6F6F6 background, 36px height, padding 0 16px, font-size 14px weight 500. Selected chip uses #000000 background with white text. Time chips for scheduling show clock icon prefix.
- **Lists**: Address suggestion lists have 56px row height, 24px location pin icon, address title at weight 500, subtitle (city, saved label) at 14px #6B6B6B. Saved places use star or home/work icons. Payment method lists show card brand icon, last 4 digits, and a radio select.
- **Checkboxes**: Custom 22px square checkboxes, 4px border-radius, 2px #000000 border unchecked. Checked fills #000000 with white checkmark. Toggle switches used more frequently — 48px wide, 28px height, #E2E2E2 track unchecked, #000000 track checked with white 24px thumb.
- **Tooltips**: #000000 background, white text, 4px border-radius, padding 8px 12px, font-size 13px. Max-width 200px. Arrow 5px. Used for surge pricing explanations and feature hints.
- **Navigation**: Bottom sheet-based navigation — no traditional nav bar. Map is the primary canvas. A draggable bottom sheet rises from the bottom with ride options. Top of screen has a back arrow and hamburger menu. Account/settings accessed via the hamburger menu side drawer with full-height #FFFFFF panel.
- **Search**: "Where to?" is the hero search element — 52px height, #F6F6F6 background, 8px border-radius, centered in the bottom sheet above recent/saved addresses. Tapping opens a full-screen search with two stacked inputs (pickup green dot, dropoff red dot) and results below.

## Spacing
- Base unit: 4px
- Scale: 4px / 8px / 12px / 16px / 24px / 32px / 48px / 64px
- Component padding: Cards 16px, bottom sheets 24px horizontal, list items 16px horizontal
- Section spacing: 8px between ride option cards, 24px between sections
- Container max width: 480px (mobile), 1200px (desktop with map)
- Card grid gap: 8px between ride option cards

## Border Radius
- 0px: Full-screen overlays, map pins
- 4px: Checkboxes, tooltips, small badges
- 8px: Buttons, cards, inputs, bottom sheet content
- 16px: Bottom sheet top corners (handle area), large modals
- 9999px: Avatars (driver photos), filter chips, status pills, vehicle type icons

## Do's and Don'ts
- Do use black (#000000) as the primary button color — it is the signature brand action color
- Do design for maps as the primary canvas; all UI floats over geographic context
- Don't use blue (#276EF1) for primary CTAs; reserve it for links and selected states only
- Do make all touch targets at least 48px for one-handed mobile use during rides
- Don't clutter the map view; show minimal UI and reveal detail through progressive disclosure via bottom sheets
- Do use bold typography for prices and ETAs — these are the most critical information at a glance
- Don't use decorative elements or illustrations in the core booking flow; utility is the aesthetic
- Do support both light and dark modes, but ensure the dark mode is true black (#000000) for OLED efficiency
- Don't use rounded corners beyond 8px on action components; the brand is geometric, not bubbly
