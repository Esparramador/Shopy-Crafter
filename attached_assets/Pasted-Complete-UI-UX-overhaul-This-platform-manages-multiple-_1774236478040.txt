═══════════════════════════════════════════════
FEEDBACK SYSTEM (most critical section)
═══════════════════════════════════════════════

1. TOAST NOTIFICATIONS (bottom-right stack):
Types: success (jade), warning (gold), error (crimson), info (sky)
Structure per toast:
- Colored icon box (rounded 7px, tinted bg)
- Title (bold 12px) + subtitle (11px muted)
- X close button
- Auto-dismiss after 5 seconds
- Slide-in from right animation, slide-out on dismiss
- Stack up to 4 toasts, oldest disappears first
- Never block content — fixed position bottom-right

Show toasts for EVERY action:
✓ "Precio aplicado en Shopify" → success toast with product name and new price
✓ "Imagen generada" → success with product name, type (Hero/Lifestyle), cost
✓ "A/B Test ganador declarado" → success with lift % and confidence %
✓ "Competidor bajó precio" → warning with product and % change
✓ "Auditoría completada" → warning if issues found, success if all good
✓ "API Error Shopify" → error with specific error code and fix suggestion
✓ "Cambiando a cliente X" → info while switching contexts
✓ "Schema aplicado" → success with count of products updated
✓ Every background task completion gets a toast

2. PROGRESS MODAL (for bulk operations):
Triggers: Boost Masivo, Generate All Images, Audit All Products, Apply All SEO
Structure:
- Dark overlay (rgba black 0.88)
- Modal 460px wide, border-radius 18px
- Title (Instrument Serif italic) + subtitle (muted)
- Step list: each step shows as pending/active/done
  pending: gray bg + gray number
  active: gold-tinted bg + gold border + animated
  done: jade-tinted bg + jade checkmark ✓
- Large progress bar (gradient gold) with % label
- Live log console: dark bg, monospace, jade text, auto-scroll
  Shows real API calls, counts, errors in real time
- Cancel button (ghost) + Complete button (gold, appears on finish)

3. INLINE LOADING STATES:
- Buttons: on click → spinner appears inside button, text stays, disabled state
- Card loading: shimmer animation (dark-to-slightly-lighter sweep)
  Use CSS: background: linear-gradient(90deg, var(--ink3) 0%, var(--ink4) 50%, var(--ink3) 100%)
  background-size: 200% auto; animation: shimmer 1.5s infinite linear
- API connecting: skeleton cards with animated shimmer before data loads
- Image generation: slot shows pulsing gold border while Replicate processes

4. EMPTY STATES (when no data):
Design beautiful empty states, never just "No data":
- Icon (large, subtle, centered)
- Title: "Aún sin imágenes" / "Catálogo vacío" / "Sin tests activos"
- Subtitle: explain why and what to do
- Primary CTA button to fix it
Example: empty images section shows a placeholder grid with dashed gold borders
and a "⚡ Generar primeras imágenes" gold button centered

5. ERROR STATES:
Never show raw error messages. Always translate to human language:
API errors map:
- 401 → "Token inválido — verifica las credenciales en Configuración"
- 402 → "Plan Shopify no incluye esta función — requiere plan Básico o superior"
- 422 → "Datos del producto incompletos — revisa título y precio"
- 429 → "Límite de API alcanzado — reintentando en 60s automáticamente"
- 5xx → "Shopify temporalmente no disponible — reintentando..."
Show with: red icon + human message + "Reintentar" button

6. CONFIRMATION DIALOGS:
For destructive actions (delete, mass repricing, replace all images):
- Full modal with clear title "¿Confirmar repricing masivo?"
- Detailed description of what will happen with specific numbers
- List of affected items with before/after values
- "Cancelar" ghost button + "Confirmar" colored button (not gold for destructive)
- Checkbox "Entiendo que esto modificará X productos en Shopify"
Never skip confirmation for irreversible actions.

7. REAL-TIME STATUS INDICATORS:
- Each motor (M1-M6) shows a status pill: active (jade pulse), paused (amber), inactive (gray)
- Per-client health score as animated circular gauge
- Notification bell badge updates dynamically
- "Última sync" timestamp updates every time data refreshes
- When action completes: relevant counter animates (number ticks up/down)

MICRO-INTERACTIONS & ANIMATIONS
═══════════════════════════════════════════════

Page transitions:
- Section content fades in + slight translateY(6px) → translateY(0) in 200ms
- CSS: opacity 0 → 1, transform translateY(6px) → translateY(0), ease

Button states:
- Default → hover: border-color brightens, background subtly shifts
- Primary (gold): hover → translateY(-1px) + gold glow shadow
- Click: scale(0.97) for 100ms (active state feel)
- Loading: spinner replaces icon, text stays, pointer-events disabled

Card hover:
- translateY(-2 to -3px) in 200ms ease
- Border-color from --bdr to --bdr2
- Subtle box-shadow appears: 0 8px 28px rgba(0,0,0,.4)
- Gold top line fades in (opacity 0 → 0.4)

Progress bar fill:
- Starts at 0 on page load
- Animates to real value in 800ms with ease-out
- Color changes smoothly if value crosses threshold (70 jade → sky → amber → crimson)

Number counters:
- When metric changes, number ticks up/down over 600ms
- CSS animation or JS requestAnimationFrame

Nav active state:
- Left gold bar slides in from opacity 0 in 150ms
- Background fades to gold tint

Notification bell:
- Badge pulses subtly when new notification arrives (scale 1 → 1.3 → 1)
- Panel slides down with opacity + translateY animation

Feed items:
- New items slide in from top with opacity animation
- Older items push down smoothly
