Klaviyo for basic flows. OmniCore writes everything.

INSTALL: npm install resend (€0 up to 3000 emails/month)

EMAIL FLOWS ENGINE:
CREATE TABLE email_flows (
  id, project_id, flow_name, flow_type,
  trigger_event, trigger_conditions,
  emails JSON, -- array of email steps
  is_active, stats JSON,
  created_at
);

CREATE TABLE email_sends (
  id, flow_id, project_id,
  recipient_email, subject, status,
  opened_at, clicked_at, sent_at
);

FLOW BUILDER UI /admin/email-flows:
Visual flow builder (no code):
[Trigger] → [Wait X days] → [Send email] →
           → [If opened] → [Send followup]
           → [If not opened] → [Different email]

OmniCore generates ALL email content:
For each flow, Claude writes:
- 3 subject line variations (A/B test)
- Full HTML email body (branded)
- Preview text
- Personalization tokens

5. VIP upgrade notification

Make the platform fully multilingual.
Target markets: España, México, Colombia, Argentina,
Chile, Perú — all Spanish but different expressions.
Also: English for international clients.

LANGUAGE ARCHITECTURE:
Store language preference per:
- Platform UI (admin/client interface)
- Generated content (product descriptions, emails)
- Store market (content generated in store's market language)

DATABASE:
ALTER TABLE projects ADD COLUMN content_language TEXT DEFAULT 'es-ES';
ALTER TABLE users ADD COLUMN ui_language TEXT DEFAULT 'es';

TRANSLATION FILES:
/locales/es.json — Español (España) default
/locales/es-mx.json — Español (México)  
/locales/es-co.json — Español (Colombia)
/locales/en.json — English

Content varies by market:
España: "tío", "guay", "mola" — informal Spanish
México: "chido", "padre", "cuate" — MX informal
Colombia: "bacano", "chimba" — CO informal
Or formal tone for all — configurable per store

CLAUDE LANGUAGE INJECTION:
When generating content, inject market:
"Generate content for market: [market].
Use vocabulary and expressions natural for 
[España/México/Colombia] consumers.
Prices in [€/MXN/COP]. 
Cultural references appropriate for [market]."

UI LANGUAGE SWITCHER:
Small flag dropdown in topbar
Changes all UI strings instantly
User preference saved to DB

OmniCore learns per market:
Separate memory entries per market:
{ niche: 'moda', market: 'mx', insight: '...' }

than Spanish fashion — OmniCore knows both
