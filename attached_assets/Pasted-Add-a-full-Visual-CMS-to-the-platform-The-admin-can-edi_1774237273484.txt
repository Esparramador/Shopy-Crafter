Add a full Visual CMS to the platform. The admin can edit ALL content
of the landing page and app UI directly from a browser-based editor —
no code, no file access, no deployment needed.
Think Webflow Editor + Shopify Theme Editor + Notion, but built-in.

INSTALL: npm install multer sharp fs-extra chokidar

PART 2: CMS API ENDPOINTS
═══════════════════════════════════════════════

All CMS endpoints require role=admin.

GET  /api/cms/content
     Returns full content.json

PATCH /api/cms/content
      Body: { path: "hero.headline", value: "Nueva headline" }
      - Updates nested path in content.json using lodash _.set()
      - Creates version snapshot before saving
      - Broadcasts change via SSE to all open editor tabs
      - Returns: { success: true, version: 43 }

POST /api/cms/content/batch
     Body: { changes: [{ path, value }, ...] }
     - Apply multiple changes atomically
     - Single version snapshot for the batch

POST /api/cms/media/upload
     Multipart form: file (image/*, max 5MB)
     - Process with sharp: resize to max 2400px, convert to WebP
     - Save to /data/cms/media/{uuid}.webp
     - Return: { url: "/media/{uuid}.webp", width, height }

DELETE /api/cms/media/:filename
       - Removes file from disk
       - Checks it's not referenced anywhere in content.json

GET  /api/cms/versions
     Returns list of last 30 versions with timestamps

POST /api/cms/versions/:id/restore
     - Restores content.json to that version
     - Creates new snapshot of current before restoring
     - Live reload all open pages

GET  /api/cms/preview
     Returns rendered HTML of landing page with current content
     (used by iframe in editor)

POST /api/cms/publish
     - Marks current content as "published"
     - Rebuilds static landing page cache
     - Optional: deploys to CDN if configured

SSE  /api/cms/events
     Server-Sent Events stream for real-time updates
     Events: content_updated, media_uploaded, version_restored

═══════════════════════════════════════════════
PART 3: VISUAL EDITOR UI (/admin/cms)
═══════════════════════════════════════════════

LAYOUT: Split panel editor (like Webflow/Framer)
- LEFT PANEL (320px): Content tree + field editors
- RIGHT PANEL: Live iframe preview of landing page
- TOP BAR: Save, Publish, Undo/Redo, Version history, Device preview

TOP BAR:
┌─────────────────────────────────────────────────────┐
│ ⚡ ShopifyAI CMS  │ ← Undo  Redo →  │ 💻 📱 📟  │
│ Cambios sin guardar (3)  │  Guardar  │  Publicar  │
└─────────────────────────────────────────────────────┘

- "Cambios sin guardar (N)" counter
- Guardar: saves to content.json (PATCH /api/cms/content)
- Publicar: makes changes live (POST /api/cms/publish)
- Device toggle: Desktop / Tablet / Mobile (changes iframe width)
- Undo/Redo: local state history (last 50 actions)

LEFT PANEL — Content Tree:
Collapsible sections matching the page structure:

▼ 🌐 Sitio
   ├─ Nombre, Logo, Colores, Fuentes
▼ 🧭 Navegación
   ├─ Links (draggable to reorder)
   ├─ CTA primario, CTA secundario
▼ 🦸 Hero
   ├─ Pill, Headline, Subheadline
   ├─ CTAs, Trust items
▼ ⭐ Features (draggable items)
   └─ [＋ Añadir feature]
▼ 📊 Estadísticas (draggable)
▼ ❓ Cómo funciona
▼ 💰 Pricing (draggable plans)
▼ 💬 Testimonios (draggable)
▼ 📣 CTA Final
▼ 🔗 Footer
