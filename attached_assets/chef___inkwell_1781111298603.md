# InkWell

Literate, editorial, long-form focused.

## Overview

InkWell is a design system crafted for writer portfolios and long-form essay blogs. It draws from print editorial traditions — sharp edges, generous margins, and a typographic hierarchy that guides the eye through thousands of words without fatigue. The warm parchment background and ink-dark text create a reading experience that feels like a beautifully typeset book. Density is spacious by design, because great writing deserves room to land.

## Shadows

**Philosophy:** Flat with borders — print-inspired, no shadows. Depth is expressed through background color shifts and typographic weight, never elevation.

| Token   | CSS Value                        |
|---------|----------------------------------|
| Subtle  | none (use Border Subtle instead) |
| Medium  | none (use Border Medium instead) |
| Large   | none (use Border Strong instead) |
| Overlay | none (use background `rgba(30, 41, 59, 0.5)` for scrim) |

**Special:** Pull quotes use a 4px left border in `#881337` with no shadow.

## Do's and Don'ts

1. **Do** keep body text line length between 45-75 characters — this is the optimal range for reading comfort.
2. **Don't** use border radius on any element — InkWell's sharp edges are a deliberate editorial choice.
3. **Do** use pull quotes with a 4px left border in Burgundy `#881337` to break up long passages.
4. **Don't** use shadows — depth is achieved through borders and background color shifts only.
5. **Do** set body text at 18px minimum with 1.8 line height — reading fatigue is the enemy.
6. **Don't** place more than one article card per row on mobile — long-form content needs full-width presence.
7. **Do** use Playfair Display at heavy weights (700-900) for headlines to create dramatic typographic contrast.
8. **Don't** use Burgundy `#881337` for body text — reserve it exclusively for links, pull quotes, and editorial accents.
9. **Do** include generous paragraph spacing (at least 24px margin-bottom) to let ideas breathe between blocks.
10. **Don't** distract from the text with autoplay media, floating widgets, or animated elements.
