PART 1: COST STRUCTURE BUILDER (COGS Engine)
═══════════════════════════════════════════════

Each product gets a full cost breakdown stored in metafields.
User inputs via a professional cost form:

COST MODEL DATA STRUCTURE:
{
  productId: string,
  costStructure: {
    // DIRECT COSTS
    unitCost: number,          // Cost to manufacture or buy (ex-factory)
    packagingCost: number,     // Boxes, bags, tissue, inserts
    labelCost: number,         // Labels, hangtags, stickers
    
    // FULFILLMENT COSTS
    shippingCostDomestic: number,    // Avg cost to ship one unit domestically
    shippingCostInternational: number,
    fulfillmentFee: number,          // 3PL fee or own warehouse cost per order
    returnRate: number,              // % of orders returned (default 8%)
    returnProcessingCost: number,    // Cost to process one return
    
    // PLATFORM COSTS (auto-calculated)
    shopifyPaymentFee: 0.015,        // 1.5% Shopify Payments (ES)
    shopifyTransactionFee: 0,        // 0% if using Shopify Payments
    shopifyPlanCostPerOrder: number, // Monthly plan cost ÷ avg monthly orders
    
    // MARKETING COSTS
    cac: number,                     // Customer Acquisition Cost (ads spend ÷ customers)
    affiliateFee: number,            // If using affiliates/influencers
    
    // OVERHEAD ALLOCATION
    overheadPerUnit: number,         // Monthly fixed costs ÷ monthly units sold
  },
  
  // AUTO-CALCULATED
  totalCOGS: number,          // Sum of all above
  breakEvenPrice: number,     // COGS × 1.0 (zero profit)
  minimumViablePrice: number, // COGS × 1.15 (15% minimum margin)
}

COGS CALCULATOR FORMULA:
totalCOGS = unitCost + packagingCost + labelCost 
           + shippingCostDomestic 
           + fulfillmentFee 
           + (returnRate × returnProcessingCost)
           + (finalPrice × shopifyPaymentFee)  // iterative calculation
           + shopifyPlanCostPerOrder
           + cac
           + overheadPerUnit

Claude explains each cost field with examples when user hovers:
"Coste de devolución: si tu tasa de devolución es 8% y cada devolución 
te cuesta €4 procesar, añade €0.32 por unidad vendida (0.08 × €4)"

PART 3: OPTIMAL PRICE CALCULATOR
═══════════════════════════════════════════════

PRICING MODELS (Claude selects the right one per product):

1. COST-PLUS PRICING (for commodity/volume products):
   price = COGS × multiplier
   Multiplier guide by category (hardcoded defaults, user can override):
   - Clothing/Fashion: 3.5x - 5x COGS
   - Electronics: 1.8x - 2.5x COGS
   - Beauty/Cosmetics: 4x - 7x COGS
   - Home Decor: 3x - 4.5x COGS
   - Food/Consumables: 3x - 6x COGS
   - Handmade/Artisan: 5x - 10x COGS
   - Digital Products: 10x - 50x COGS (marginal cost near zero)
   - Supplements: 5x - 8x COGS
   - Jewelry: 4x - 8x COGS
   - Sports/Fitness: 2.5x - 4x COGS

2. COMPETITIVE PRICING (for market-defined products):
   price = competitorMedian × positionMultiplier
   positionMultiplier: budget=0.85, parity=1.0, premium=1.15, luxury=1.35

3. VALUE-BASED PRICING (for unique/branded products):
   Claude estimates perceived value: "What would a customer in [audience] 
   be willing to pay for this product given its benefits?"
   Anchors: pain_solved × willingness_to_pay

4. PSYCHOLOGICAL PRICING (always applied as final step):
   Round to nearest psychological price point:
   - Under €10: round to x.99 (€8.99, €9.99)
   - €10-50: round to x.95 or x.99 (€24.95, €34.99)
   - €50-100: round to x.90 or x.95 (€79.90, €89.95)
   - €100-500: round to x9 or x5 (€149, €199, €249)
   - Over €500: round to clean numbers (€599, €799, €999)
   
   COMPARE_AT_PRICE (fake original price for FOMO):
   compare_at = optimal_price × 1.30 (30% "discount" minimum)
   Also round psychologically. Never show <20% discount (weak) or >60% (suspicious)

MARGIN WATERFALL VISUALIZATION:
Show the user a breakdown of every €1 of revenue:
Revenue: €100
- Platform fees: -€1.50 (1.5%)
- COGS unit: -€18.00 (18%)
- Packaging: -€2.00 (2%)
- Shipping: -€4.50 (4.5%)
- Returns provision: -€1.60 (1.6%)
- Marketing (CAC): -€12.00 (12%)
- Overhead: -€5.00 (5%)
