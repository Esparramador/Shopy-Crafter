💡 Tips para usar este prompt
1. Pásaselo en partes si es muy largo — Replit Agent funciona mejor con bloques. Puedes hacer:

Primer mensaje: secciones de Estética + Componentes 1-3
Segundo mensaje: Componentes 4-7 + Reglas críticas

2. Adjúntale el screenshot del widget que te mostré antes — un Agent visual con referencia construye mucho más fiel que solo con texto.
3. Si quieres iterar después, dile cosas tipo:

"La tabla TCO se ve bien pero la fila ganadora no tiene suficiente énfasis visual — añade un glow sutil teal en el border-left y un pequeño icono ★ a la izquierda del nombre"

4. Para forzar que NO se invente backend, repite al final:

"Recordatorio: NO modifiques /server/. NO crees rutas. Solo CONSUME los endpoints existentes que descubras leyendo el código actual"
