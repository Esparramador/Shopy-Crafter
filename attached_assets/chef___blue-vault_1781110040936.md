# Blue Vault

## Overview
Blue Vault is a clean, playful design system built for file management and creative collaboration. It pairs a confident electric blue with generous white space, warm accent colors, and illustration-friendly layouts. The aesthetic is approachable and simple — making the complex act of organizing digital life feel effortless, even delightful. Every component favors clarity over density, with breathing room that signals trust and calm.

## Colors
- **Primary** (#0061FF): Primary CTAs, selected items, active navigation, links — Dropbox Blue
- **Primary Hover** (#0050D4): Hover state for buttons, darker interactive moments — Deep Cobalt
- **Secondary** (#FFD830): Illustration accents, highlight backgrounds, onboarding warmth — Sunshine Yellow
- **Accent Coral** (#FF7B72): Notification badges, illustration accents, warm highlights — Soft Coral
- **Neutral** (#637282): Secondary text, metadata, file details — Steel Gray
- **Background** (#FFFFFF): Main app background, file canvas — White
- **Surface** (#F7F5F2): Card backgrounds, sidebar panels, settings areas — Warm Linen
- **Text Primary** (#1E1919): File names, headings, primary readable content — Near Black
- **Text Secondary** (#637282): File sizes, dates, secondary metadata — Steel Gray
- **Border** (#D6D1CB): Dividers, card borders, drag outlines — Warm Gray
- **Success** (#11A85C): Upload complete, synced indicators, file saved — Emerald
- **Warning** (#F7A600): Storage warnings, shared link expiring — Tangerine
- **Error** (#D32F2F): Upload failed, file conflict, error messages — Brick Red

## Typography
- **Display Font**: Space Grotesk — loaded from Google Fonts
- **Body Font**: DM Sans — loaded from Google Fonts
- **Code Font**: JetBrains Mono — loaded from Google Fonts

Space Grotesk brings a distinctive geometric personality to headings and display text, with its signature sharp curves and monospaced DNA lending a technical-yet-friendly character. Used at weight 700 for headlines and marketing surfaces. DM Sans handles body text at weight 400 for file names and metadata, weight 500 for interactive labels, and weight 700 for emphasized elements. The pairing creates a clear hierarchy: Space Grotesk announces, DM Sans informs.

Type scale: 12px (micro/file meta) / 14px (body) / 16px (file name/subtitle) / 20px (section title) / 28px (page heading) / 40px (marketing hero)

## Elevation
Elevation is gentle and warm, using soft shadows that complement the linen-toned surfaces. Default cards use no shadow, relying on the warm surface color against white backgrounds for separation. Hover cards add `box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08)`. Modals use `box-shadow: 0 8px 32px rgba(0, 0, 0, 0.12)` with a scrim at rgba(0, 0, 0, 0.4). Dropdowns use `box-shadow: 0 2px 12px rgba(0, 0, 0, 0.1)`. Drag-and-drop states add a dashed 2px #0061FF border with #EBF0FF background tint.

## Do's and Don'ts
- Do use generous white space — the design system communicates trust through breathing room
- Do use the warm surface color (#F7F5F2) for sidebars and panels to create subtle depth without shadows
- Don't overuse Dropbox Blue; reserve it for interactive elements and selected states only
- Do use illustration and the yellow accent (#FFD830) for onboarding and empty states
- Don't make the interface feel dense; if it looks like a file manager from the 2000s, add more space
- Do show file type icons consistently — they are the primary visual anchor in file views
- Don't use harsh borders; prefer warm gray (#D6D1CB) over cool gray for all dividers
- Do support drag-and-drop interactions with clear visual affordances (dashed blue border, blue tint)
