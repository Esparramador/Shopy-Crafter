# Módulo A/B Testing — Shopy Crafter

Sistema completo de A/B testing inteligente con análisis IA real.
Reemplaza el `/ab-testing` actual con tests funcionales de **Imagen** y **Precio**.

---

## 🎯 Qué resuelve

El módulo actual es un formulario hueco que no hace nada real. Este nuevo:

### Test de Imagen
- **Analiza la imagen actual** con Claude (composición, iluminación, contexto, apelación)
- **Genera 4 variantes IA** (Lifestyle, Studio, Contexto, Detalle) con Runway/Replicate
- **Da score 0-100 a cada variante** y recomienda la mejor automáticamente
- **Compara visualmente** las 5 opciones (original + 4 variantes) en grid
- **Lanza split traffic real** entre la imagen actual y la variante elegida

### Test de Precio
- **Scrapea competencia** en múltiples fuentes (Amazon, Shopify stores, marketplaces)
- **Analiza proveedores alternativos** (conecta con Supplier Intelligence) para sugerir reducción de COGS
- **Recomienda 3 niveles** de precio (conservador / óptimo / agresivo) con justificación de Claude
- **Lanza split traffic** entre precio actual y nuevo precio

## 🧠 Lógica del backend (puntos clave)

### `image/analyze` — Análisis de imagen con Claude

```
1. Descarga imagen del producto Shopify
2. Convierte a base64
3. Llama a Claude Opus 4.7 con vision:
   "Analiza esta imagen de producto e-commerce. Devuelve JSON con scores 0-10
   en composición, iluminación, contexto, apelación, claridad. Lista warnings
   y sugerencias de mejora."
4. Guarda en cache (no re-analizar misma imagen)
```

### `image/generate-all` — Generar 4 variantes

```
1. Para cada estilo (lifestyle, studio, context, detail):
   - Construye prompt específico según estilo + producto
   - Llama a Runway Gen-3 / Replicate / Flux Pro / SD3
   - Costo: ~€0.30/imagen
2. Sube las imágenes resultantes a tu CDN
3. Para cada variante, ejecuta image/analyze
4. Devuelve las 4 con scores
```

### `price/competitors` — Scraping de competencia

```
1. Construye queries de búsqueda con título producto
2. Usa SerpAPI o similar para buscar en:
   - Google Shopping
   - Amazon
   - Marketplaces específicos del nicho
   - Otras Shopify stores (search por título)
3. Scrapea precios con Firecrawl/Playwright
4. Filtra por similitud (Claude evalúa si producto es realmente comparable)
5. Calcula stats: min, max, mediana, percentil del precio actual
```

### `price/supplier-impact` — Conecta con Supplier Intelligence

```
1. Llama internamente a /api/suppliers/search filtrando por categoría producto
2. Para cada proveedor encontrado, calcula su COGS hipotético
3. Compara con COGS actual y devuelve ahorro potencial
```

### `price/recommend` — Recomendación con Claude

```
Llama a Claude Opus 4.7 con TODO el contexto:
- Producto + categoría
- Precio actual + COGS actual
- Análisis de competencia (mediana, posición)
- Análisis de proveedores (mejor opción)
- Histórico de ventas si lo tienes

Pide que devuelva 3 niveles de precio + justificación + riesgos.
```

### Schema mínimo necesario

```sql
CREATE TABLE ab_tests (
  id TEXT PRIMARY KEY,
  shop_id INTEGER NOT NULL,
  product_id TEXT NOT NULL,
  type TEXT NOT NULL,              -- 'image' | 'price'
  status TEXT NOT NULL,            -- 'draft' | 'running' | 'paused' | 'completed' | 'cancelled'
  config JSONB NOT NULL,
  hypothesis TEXT NOT NULL,
  winner_variant TEXT,             -- 'A' | 'B' | NULL
  insights JSONB,
  created_at TIMESTAMP DEFAULT NOW(),
  started_at TIMESTAMP,
  completed_at TIMESTAMP,
  winner_applied_at TIMESTAMP
);

CREATE TABLE ab_test_events (
  id SERIAL PRIMARY KEY,
  test_id TEXT REFERENCES ab_tests(id),
  variant TEXT NOT NULL,           -- 'A' | 'B'
  event_type TEXT NOT NULL,        -- 'view' | 'add_to_cart' | 'purchase'
  visitor_id TEXT,
  revenue NUMERIC,
  occurred_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE image_analyses (
  image_url TEXT PRIMARY KEY,
  scores JSONB,
  analyzed_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE generated_image_variants (
  id TEXT PRIMARY KEY,
  product_id TEXT NOT NULL,
  style TEXT NOT NULL,
  url TEXT NOT NULL,
  prompt TEXT,
  generation_provider TEXT,
  generation_cost NUMERIC,
  analysis JSONB,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE competitor_analyses (
  id SERIAL PRIMARY KEY,
  product_id TEXT NOT NULL,
  competitors JSONB,
  price_stats JSONB,
  scraped_at TIMESTAMP DEFAULT NOW()
);
```

## ✅ Estados UI manejados

Cada botón maneja: `idle` → `confirming` (si requiere) → `loading` → `success`/`error` (1.5s) → `idle`.

Estados especiales:
- **Generación de imagen**: spinner dentro de la card vacía + bloqueo de selección
- **Análisis multi-fuente**: pantalla loading con texto "Scrapeando competencia · Buscando proveedores..."
- **Polling de stats live**: cada 5s mientras test esté `running`
- **Confianza estadística**: barra que se llena según %, color teal cuando >95%

## 🔧 Personalización

### Cambiar proveedores de generación de imagen

En backend, en `image/generate-variant`, puedes elegir entre:
- **Runway Gen-3** — mejor calidad, más caro (~€0.50/imagen)
- **Replicate Flux Pro** — buena calidad, balance precio (~€0.30)
- **DALL·E 3** — buen precio, calidad media (~€0.20)
- **Stable Diffusion XL** — más barato (~€0.05) pero peor

Sugerencia: usa Flux Pro por defecto, fallback a SD si falla.

### Cambiar fuentes de scraping competencia

En `price/competitors`, las fuentes recomendadas en orden:
1. **SerpAPI** — Google Shopping (€0.005/búsqueda)
2. **Firecrawl** — scraping cualquier URL (€0.001/página)
3. **Apify** — scrapers especializados Amazon/eBay (€0.10-0.50/run)

## 🐛 Errores comunes

**"Tests siempre muestran 'Sin datos aún'"**
→ Verifica que el split traffic esté instalado en tu tienda Shopify.
   Necesitas un script en theme.liquid que envíe eventos a `/api/ab-testing/track`.

**"Variante IA no se genera"**
→ Verifica que la API key de Runway/Replicate esté configurada en `.env`
→ Verifica que tienes créditos en la cuenta del proveedor

**"Competencia devuelve 0 resultados"**
→ Tu producto puede ser muy nicho. Prueba con queries más genéricas.
→ Verifica que SerpAPI/Firecrawl tienen créditos.

**"Significancia estadística nunca llega a 95%"**
→ Necesitas más tráfico. Cálculo orientativo:
   - 1.000 visitas/variante: detecta lift de ~20%+
   - 5.000 visitas/variante: detecta lift de ~10%+
   - 20.000+ visitas/variante: detecta lift de ~5%+

## 🎓 Patrón a aplicar en OTROS módulos

Una vez funcione A/B Testing y Pricing, aplica el mismo patrón a:

1. **Auditoría** — `<ActionButton>` en "Ejecutar auditoría", "Aplicar fix"
2. **Rediseño IA** — `<ActionButton>` con `estimatedCost` en cada acción
3. **Imágenes** — wizards similares para "Mejorar imagen", "Eliminar fondo"
4. **Consistencia** — `<ActionButton>` en "Analizar marca", "Aplicar guía"
5. **SEO Engine** — `<ActionButton>` en "Generar meta tags", "Optimizar URLs"

El secreto está en el componente `<ActionButton>`. Cualquier `<button>` rota
de la app se reemplaza por `<ActionButton>` con su `onAction={async () => {...}}`
y los estados se manejan automáticamente.
