CLIENT DASHBOARD UI — specific design requirements:

The client view must feel PREMIUM but SIMPLIFIED vs admin panel.
Client is a business owner, not a tech person. Show results, not tools.

KEY PRINCIPLE: "Tu agencia trabaja para ti" feeling.
Client should feel they have a professional team optimizing their store 24/7.

HEADER BANNER (top of every client page):
"[StoreName] · Gestionado por [AgencyName]"
Small text: "6 motores de IA activos · última optimización hace X min"
Subtle green pulse dot

METRIC CARDS use Instrument Serif for numbers — feels prestigious.
Add context under each number:
Not just "€32,400" but "€32,400 en ventas este mes (+22% vs mes anterior)"

ENGINE STATUS PANEL:
Show M1-M6 as a visual "control room" feel:
Each engine as a card showing:
- Engine name ("Generación de Imágenes", "Optimización de Precios", etc.)
- Status pill: "Activo" (green pulse) / "Procesando" (amber spin) / "Completado" (check)
- Last action: "Generadas 48 imágenes hace 2h"
- Impact: "+€840 revenue atribuido"

ACTIVITY TIMELINE:
Not a simple feed — a proper timeline with dates:
[HOY]
  ✓ 09:14 — 24 imágenes Hero generadas y subidas a Shopify
  ✓ 09:01 — Auditoría completada: 3 productos mejorados
[AYER]
  ✓ 18:32 — A/B Test "Bomber Jacket" declaró ganador (+28% conv.)

[LUNES]
  ...
