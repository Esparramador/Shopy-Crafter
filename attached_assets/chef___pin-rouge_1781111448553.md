# Pin Rouge

## Overview
Pin Rouge is a warm, visually-driven design system designed for discovery and inspiration. Anchored by a bold red and softened by rounded forms and generous white space, it creates an inviting canvas for visual content. The masonry grid layout philosophy permeates every decision — content flows naturally, edges are soft, and the UI gracefully steps aside to let images spark creativity and aspiration.

## Colors
- **Primary** (#E60023): Save buttons, primary CTAs, brand logo, and active pins — Pinterest Red
- **Primary Hover** (#CC001F): Hovered and pressed primary actions — Dark Cherry
- **Secondary** (#5F5F5F): Secondary actions, muted icons, and supporting text — Graphite
- **Neutral** (#767676): Metadata text, pin descriptions, board counts — Stone Gray
- **Background** (#FFFFFF): Main canvas, pin detail modal backdrop — White
- **Surface** (#F9F9F9): Search bar background, settings panels — Near White
- **Text Primary** (#333333): Pin titles, board names, profile names — Dark Charcoal
- **Text Secondary** (#767676): Descriptions, follower counts, timestamps — Stone Gray
- **Border** (#CDCDCD): Subtle dividers, input borders, section separators — Soft Silver
- **Success** (#0FA573): Board save confirmation, successful uploads — Jade Green
- **Warning** (#EBA800): Broken link indicators, pending states — Goldenrod
- **Error** (#CC001F): Delete confirmations, upload failures, report flags — Dark Cherry

## Typography
- **Display Font**: Nunito Sans — loaded from Google Fonts
- **Body Font**: Nunito Sans — loaded from Google Fonts
- **Code Font**: JetBrains Mono — loaded from Google Fonts

Nunito Sans provides the friendly, rounded character that complements the soft visual aesthetic. Display headings use weight 800 with standard letter-spacing for bold impact. Body text uses 14px weight 400 with 1.4 line-height. Pin titles use 16px weight 700. Board names and interactive labels use weight 600. The rounded terminals of Nunito Sans mirror the generous border-radius used throughout the component system, creating visual harmony.

Type scale: 12px (micro) / 14px (body/description) / 16px (pin title) / 20px (section title) / 24px (board heading) / 36px (hero/landing)

## Elevation
The masonry grid pins use subtle shadows to create a layered feel against the white canvas. Default pin cards have no shadow (they float via visual content alone). Hover state adds `box-shadow: 0 0 12px rgba(0, 0, 0, 0.15)` with a slight scale transform (1.02). Pin detail modals use `box-shadow: 0 2px 16px rgba(0, 0, 0, 0.12)` with rounded corners. The close-up modal overlay uses rgba(0, 0, 0, 0.6) backdrop. Dropdowns use `box-shadow: 0 1px 8px rgba(0, 0, 0, 0.12)`.

## Components
- **Buttons**: Primary buttons have #E60023 background, white text, 24px border-radius (pill), height 40px, padding 0 20px, font-weight 700, font-size 15px. Hover darkens to #CC001F. Secondary buttons have #EFEFEF background, #333333 text, same pill radius. "Save" button appears on pin hover as a compact 32px height pill in #E60023. Ghost buttons use transparent background with #333333 text.
- **Cards**: Pin cards have no fixed height — they conform to image aspect ratio. Border-radius 16px, overflow hidden. No border in grid view. On hover, a dark gradient scrim appears at bottom for title/action overlay. Pin cards have a "Save" button (top-right), a link-out icon (bottom-right), and a three-dot menu (bottom-right) that all appear on hover. Board preview cards show a collage of 3 images with 2px gap, 16px border-radius.
- **Inputs**: Text inputs have 2px solid #CDCDCD border, 16px border-radius, height 48px, padding 0 16px, font-size 16px. Focus state changes border to #333333 with no shadow. Search is the dominant input — see Search component. Textarea inputs have 12px padding and min-height 80px.
- **Chips**: Topic chips are pill-shaped with #EFEFEF background, 14px weight 600, padding 8px 16px, 24px border-radius. Selected chips use #333333 background with white text. Interest selection chips during onboarding use 48px height with icon + label.
- **Lists**: Board lists show 60px square thumbnails (3-image collage), board name at weight 700, pin count at 14px #767676. List items have 12px vertical padding. Hover highlights with #F9F9F9 background.
- **Checkboxes**: Custom 24px rounded square (8px border-radius), 2px #CDCDCD border unchecked. Checked fills #333333 with white checkmark. Used in board selection and settings.
- **Tooltips**: #333333 background, white text, 12px border-radius, padding 8px 16px, font-size 14px, max-width 200px, weight 600. Arrow 6px. Delay 200ms. Appear on icon buttons in the pin action bar.
- **Navigation**: Top bar 56px height, white background, 1px bottom border #CDCDCD. Logo left, search center (expanded), icons right (notifications, messages, profile). Active nav uses bold weight, no color change. Mobile bottom tab bar has 4 icons (Home, Search, Notifications, Profile) at 48px height.
- **Search**: Dominant top-bar search fills available width, 48px height, #F1F1F1 background, 24px border-radius, with 16px magnifying glass icon. Typeahead shows trending searches, recent searches, and idea suggestions with thumbnail previews. Search results default to a masonry grid of pins.

## Spacing
- Base unit: 4px
- Scale: 4px / 8px / 12px / 16px / 20px / 24px / 32px / 48px
- Component padding: Pin cards 0px (image is edge-to-edge within radius), pin detail 24px
- Section spacing: 32px between board sections on profile, 16px between topic rows
- Container max width: 1260px (masonry grid area), no max on masonry columns (fluid)
- Card grid gap: 16px vertical and horizontal in masonry grid (desktop), 8px on mobile

## Border Radius
- 8px: Checkboxes, small tooltips, compact elements
- 12px: Dropdown menus, small cards
- 16px: Pin cards, board previews, modals, buttons (large variants)
- 24px: Buttons (standard pill), search bar, chip components
- 9999px: Avatars, notification badges, small pills

## Do's and Don'ts
- Do use the masonry grid layout for all visual content discovery — never use rigid equal-height grids
- Do keep pin cards borderless with only border-radius and shadow on hover for a clean canvas
- Don't use red (#E60023) for anything except the brand and save/pin actions
- Do show hover overlays with gradient scrims for pin interactions — never place persistent UI over images
- Don't force square aspect ratios on pins; respect the original image proportions
- Do use generous 16px border-radius on all card-like elements for the signature soft feel
- Don't add excessive text to pin cards; the image is the content, text is secondary
- Do group related pins into boards with clear visual collage previews
- Don't use sharp corners anywhere in the interface; maintain rounded softness consistently
